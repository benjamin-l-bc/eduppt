# 《AI伴我成长》一年级 AI 启蒙课

建平实验小学 一（8）班 · 35 分钟 · 让小朋友认识 AI，并明白：**想用好 AI，靠的是自己的语文、数学、英语本领。**

## 上课直接用这三个文件

| 文件 | 内容 |
|---|---|
| `AI伴我成长.pptx` | 23 页课件。**每页的演讲者备注里都有台词、时间点和互动/表演提示**，建议用“演示者视图”放映 |
| `教案.pdf`（源文件 `教案.md`） | 教学目标、课前准备清单、35 分钟流程表、三个核心游戏的“演法”、课堂管理和时间弹性 |
| `课堂教具打印包.pdf` | A4 横向：魔法公式大卡 ×4、英语指令卡 ×6、⭕/❌ 举牌、机器人头套贴纸、「AI 小训练师」奖励贴纸 |

## 课程结构：找到三件法宝

1. **认识 AI**：猜谜 → 揭晓 → 身边的 AI → 游戏「AI 能不能？」（AI 能帮你吃青菜吗？能帮你长高吗？）
2. **法宝一·语文**：想要兔子 AI 却画了章鱼 → ★ 指挥“机器人老师”戴帽子、画笑脸 → 说清楚的魔法公式
3. **法宝二·数学**：数一数 AI 画的六指手 → ★ AI 小侦探（1 个苹果 + 1 个苹果 = 11 个？）
4. **法宝三·英语**：hot dog 被 AI 翻成“一只很热的狗” → ★ Robot, please! 英语指令游戏
5. **总结**：三件法宝 → 和 AI 做朋友的四个约定 → 拍手口诀 → 颁发贴纸

## 重新生成（修改内容后）

```bash
npm install
npm run all        # = assets（图片素材）+ build（课件）+ materials（PDF）
```

课件内容在 `src/build-deck.js`，打印材料在 `src/build-materials.js`，教案改 `教案.md` 后运行 `npm run materials`。生成 PDF 需要 Playwright + Chromium。
